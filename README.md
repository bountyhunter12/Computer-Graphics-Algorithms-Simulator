# Computer Graphics Algorithms Simulator

A single-page simulator for learning and demonstrating important **computer graphics algorithms** through an interactive grid-based user interface.

## Overview

This project was built as a **Computer Graphics sessional lab project**. It allows users to select an algorithm, provide input values, and see the output directly on the canvas. The simulator focuses on simple visualization so the working process of each algorithm becomes easier to understand.

## Features

* Line drawing algorithms
* Circle drawing algorithm
* Polygon filling algorithms
* Basic 2D transformations
* Clipping algorithms
* Hidden surface detection algorithms
* Interactive canvas-based output
* Simple control panel for input and execution

## Algorithms Included

### Line Drawing Algorithms

* DDA Line Drawing Algorithm
* Bresenham Line Drawing Algorithm

### Circle Drawing Algorithm

* Midpoint Circle Drawing Algorithm

### Polygon Filling Algorithms

* Boundary Fill Algorithm
* Flood Fill Algorithm

### Basic 2D Transformations

* Translation
* Scaling
* Rotation
* Shearing
* Reflection

### Clipping Algorithms

* Cohen–Sutherland Line Clipping Algorithm
* Sutherland–Hodgman Polygon Clipping Algorithm

### Hidden Surface Detection Algorithms

* Back-Face Culling
* Z-Buffer Algorithm
* Painter's Algorithm

## Technologies Used

* HTML
* CSS
* JavaScript / TypeScript
* React-style component-based UI
* Canvas rendering
